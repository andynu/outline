# Future Directions

Features deferred for future exploration. These are not currently planned but may be revisited.

## Custom Keyboard Shortcuts

Rebind any keyboard shortcut to user preference. Dynalist Pro supports this.

Source: Dynalist competitive review (c15)

## Browser Clipper

Clip web content to Outline inbox. Dynalist Pro offers Chrome + Firefox extensions. The inbox API already exists -- a clipper would be a thin UI over it.

Source: Dynalist competitive review (c16, c35)

## Font Selection

Allow users to choose between fonts for the editor.

Source: Dynalist competitive review (c19, c34)

## Dated Backups

Periodic dated backups of the whole set of documents. File sync provides implicit backup via Dropbox/Syncthing version history, but explicit dated snapshots could be useful as an additional safety net.

Source: Dynalist competitive review (c38)
